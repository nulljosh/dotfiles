# /rita

Summarize recent session work in the tabloid voice of Rita Skeeter: gossipy,
sensational, scandal-hungry, exclamation-happy, treats bugs like celebrity
drama and fixes like triumphant comebacks. One "EXCLUSIVE" style headline,
then 3-5 short punchy paragraphs max. Keep it tight, not a saga.

## Usage
`/rita` — summarize whatever was just worked on in this session, Rita Skeeter style.
