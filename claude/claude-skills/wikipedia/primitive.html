Primitive

Email infrastructure built for AI agents, not humans

Primitive (stylized primitive.dev) is an email infrastructure product that exposes sending and receiving email as an HTTP REST API, aimed at AI agents rather than traditional application backends. Instead of an agent managing SMTP credentials or a mail server, Primitive issues managed *.primitive.email addresses that receive real mail and can trigger hosted JavaScript functions on inbound messages.[1]

Overview

The product is positioned around a claim that "every hop in the email pipeline runs on primitive-owned servers, end-to-end," and that a direct SMTP delivery returns the recipient's 250 OK plus a queue ID within the same request.[1] Primitive also markets managed sending-IP reputation, automatic bounce and complaint processing, and a built-in spam-filtering pipeline, framing these as problems normally handled by dedicated email infrastructure teams.[1]

Features

Email operations

  • HTTP REST API for sending and receiving email
  • Managed *.primitive.email subdomain addresses for receiving real mail
  • Hosted JavaScript function execution on inbound messages, replacing always-on consumer processes
  • A "chat" verb for sending a message and receiving a threaded reply in a single round trip
  • Custom domain support with managed SPF, DKIM, DMARC, and TLS-RPT authentication

Developer tooling

  • Official SDKs for Node.js, Python, and Go, generated from an OpenAPI 3.1 specification
  • A command-line tool
  • A Model Context Protocol (MCP) server exposed over Streamable HTTP
  • A Natural Language Web (NLWeb) query endpoint

Authentication

API access uses bearer tokens: API keys prefixed prim_ or OAuth access tokens prefixed prim_oat_, with OAuth authorization-server metadata published at standard .well-known endpoints.[1]

Pricing

Primitive publishes three usage-based tiers, metered against email volume, storage, function invocations, and runtime.[1]

Integrations

Primitive advertises compatibility with Claude, Cursor, VS Code / GitHub Copilot, and Goose, and can be installed as a skill inside Claude Code and similar coding agents.[1]

Open source

Primitive's SDKs and command-line tool are published publicly on GitHub under the primitivedotdev/sdks repository, while the hosted email infrastructure itself remains proprietary.[1]
