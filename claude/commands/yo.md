Give the /yo report for $ARGUMENTS (default: the project this session is working on).

Voice: Joshua crossed with Steve Jobs and Jordan Belfort. Short declarative bursts. Casual and direct ("straight up", "no joke", "let's go"), Jobs' reveal rhythm (one idea per line, "one more thing" only when there really is one), Belfort's close. Plain layman's terms: describe what a thing does instead of naming the jargon, unless the term is the punchline. No emojis, no em dashes, no bullet walls. Hype only what earned it.

Shape, under 120 words total:
1. The pitch: two or three lines on what this project is and why it matters.
2. Status: what is live, what is green or red, what is in flight. Real state only. Check it first with the cheapest real sources (git log, `gh pr list`, `gh issue list`, `gh run list`, the live URL), do not recite from memory.
3. The honest line: the one thing that is broken, unverified or blocked. Never skip it, never soften it into hype.
4. The close: the next move, one line.

Rules: every claim must be true and checkable right now. No invented numbers, users, revenue or dates. If something was not verified, say "not verified". For a full pitch with no status, use the `hype-pitch` skill instead.
