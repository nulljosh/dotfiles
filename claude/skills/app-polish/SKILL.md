# /app-polish <app>

Reference implementation: `~/Documents/Code/airwell/ios/App` (Theme.swift, SettingsView.swift, AirwellApp.swift). Copy the pattern, not the colours.

## 1. Read first
Every screen, every tab, the model layer. List the tabs and every `Text`, `Button`, `Toggle`, `Picker`. Do not start editing until you know the flow.

## 2. Theming (Settings)
- `Palette` = background, content colour, accent, each an `RGB` (sRGB doubles, Codable). 4 to 5 presets plus **Custom** with `ColorPicker`s.
- Inject via `@Environment(\.palette)`. Replace every hardcoded colour. `preferredColorScheme` comes from background luminance.
- Contrast is computed, never trusted: text on a custom colour is black or white by WCAG ratio. Button labels too.
- Persist theme id and custom palette in UserDefaults. Swatches are 44pt+ buttons with a label and `.isSelected`.

## 3. Accessibility
- Every control has a label. Decorative images `.accessibilityHidden(true)`. Stat tiles `.combine`.
- Live elements get `.updatesFrequently`; phase changes post `AccessibilityNotification.Announcement`.
- Dynamic Type: text styles only, `minimumScaleFactor` on tight spots, lists and onboarding scroll.
- Reduce Motion: replace movement with opacity. Contrast 4.5:1 minimum.
- Run the `xcode-integration` VoiceOver, Dynamic Type and contrast specialists on each view.

## 4. Languages
- `Localizable.xcstrings` is generated by a script (`scripts/make_strings.py`, one row per key, one column per language). Languages: es fr de it pt-BR ja ko zh-Hans zh-Hant ru ar. Arabic proves RTL.
- `Text("literal")` localizes itself. Anything that is a `String` goes through `String(localized:)` or `L()`. Interpolations become `%lld` / `%@` keys.
- List `CFBundleLocalizations` in Info.plist when the plist is hand-written.
- Check: launch with `-AppleLanguages (de)` and `(ar)` and screenshot every tab.

## 5. Haptics and animation
- `.sensoryFeedback` on selection, start/stop, toggles, theme. Gate all of it on the user's haptics switch.
- `.smooth` / `.snappy` on state changes, `contentTransition(.numericText())` on numbers, `symbolEffect` for idle life. All off or quiet under Reduce Motion.

## 6. Onboarding
Run `/onboarding`. Stocks style, one screen, one button, shows once.

## 7. Verify
Build iOS and macOS, run tests, then walk every tab in the simulator in dark, light, a large Dynamic Type size, and two languages. Fix, rebuild. Do not call it done off a green build alone.

## 8. Launch
Run `/launch` and `/producthunt`. Update `launch/producthunt.md`, gallery and first comment to match what the app really does now. Prepare everything and stop: Joshua clicks Schedule/Submit, and nothing gets posted without his yes.
