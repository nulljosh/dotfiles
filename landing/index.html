Four files, one setup

Your terminal, in a repo

Every config lives in git and is symlinked into place. Edit it live and the change is already in the repo.

zsh

The shell macOS ships with

PATH, completions, fnm, fzf, zoxide and atuin. Tools you have not installed are skipped instead of erroring.

fish

The shell you actually type in

The same tools as zsh, plus git abbreviations that expand as you type. gs becomes git status.

Ghostty

A fast, native terminal

JetBrains Mono with Nerd Font glyphs, slightly translucent, and it opens straight into fish.

Starship

A prompt that says where you are

Catppuccin Mocha powerline: user, time, folder, branch and language version. A plain variant takes over in Terminal.app.

Portable

Intel and Apple silicon

Homebrew is found at /opt/homebrew or /usr/local. No paths to edit.

Safe

Backs up first

Anything already in the way is moved to .bak before the link goes in.

Private

Secrets stay local

API keys live in secrets.zsh and secrets.fish, sourced if present, never committed.

Install

Three commands

Clone it, install the tools, link the files. Run it again any time; it only replaces links.

01

Clone

Anywhere you like. The installer links from wherever the repo sits.

02

Install the tools

All from Homebrew. Skip any you do not want; the configs check before they use one.

03

Link

install.sh symlinks five files and backs up whatever was there.
